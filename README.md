# 外構かんたんプラン

外構工事の **現地調査 → 平面図 → 3Dパース → 見積もり** を、スマホ・タブレット・PC のブラウザだけで進められるアプリです。
現地調査と見積もりは、経験のない人でも「質問に答える・測る・選ぶ」だけで終わるように作っています。

## できること

| 画面 | 内容 |
| --- | --- |
| 1. 現調 | 10 ステップの質問に答えるだけ。敷地と建物は図の A〜F を測って入力。写真は撮る場所のチェックリストつき。回答から「気をつけるポイント」（高低差・乗り入れ口・境界杭・重機が入れない等）を自動で表示。現調シートを印刷できます。 |
| 2. 平面図 | 現調の数字とご要望から、たたき台を自動で作成。部材をタップで選び、ドラッグで移動、角の丸で大きさを変更（敷地や他の部材の端に吸着）。部材を置くたびに概算金額が変わります。 |
| 3. 3D | 平面図がそのまま立体に。視点（ななめ・正面・目線・真上）と時間帯（昼・夕方・夜）を切り替え、画像として保存、見積書への添付ができます。 |
| 4. 見積 | 平面図の面積・長さ・個数 × 単価で自動計算。数量・単価の手直し、行の除外、手入力の行、諸経費・値引き・消費税に対応。見積書（＋平面図＋完成イメージ）を印刷・PDF 保存できます。 |

そのほか

- **単価表**（設定）：材料と工事費を合わせた単価を自社の金額に書き換えられます。
- **会社情報**（設定）：見積書に印刷される会社名・住所・インボイス登録番号など。
- **バックアップ**（設定）：全データ（写真を含む）を 1 つのファイルに書き出し・読み込み。
- はじめて開くとサンプル案件が 1 件入っています。

## 使い方の流れ

1. 「新しい案件」をつくり、現調の質問に順番に答える（敷地の幅と奥行だけは必須）。
2. 「まとめ」で **平面図を自動作成**。
3. 平面図で位置や大きさを直し、必要な部材を「部材を追加」から置く。
4. 3D で確認し、気に入った視点で「見積書に添付」。
5. 見積で数量・単価を確認し、「見積書をつくる」→「印刷・PDF保存」。

## 単価についての注意

初期値の単価はあくまで **参考値**（材工共・税抜）です。地域・仕入れ・現場条件で変わるため、
実際に使う前に、設定の「単価表」で自社の単価に変更してください。

## データの保存先

サーバーは使いません。データは **その端末のブラウザの中**（案件は localStorage、写真は IndexedDB）に保存されます。

- ブラウザのデータを消すと案件も消えます。定期的に設定の「バックアップ」で書き出してください。
- 別の端末に移すときも、バックアップの書き出し → 読み込みで移せます。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 単体テスト（見積計算・自動レイアウト・編集の計算）
npm run build      # 型チェック＋本番ビルド（dist/ に出力）
npm run preview    # ビルド結果の確認
```

React + TypeScript + Vite、3D は three.js です。

`VITE_DEMO=1 npm run build` でビルドすると、ホームに「お試し用のページです」という案内が出ます
（印刷やファイル保存ができない埋め込み環境で見せるとき用）。

### 公開のしかた

`npm run build` でできる `dist/` フォルダは静的ファイルだけなので、GitHub Pages・Netlify・Vercel・
社内サーバーなど、どこに置いても動きます（`base: './'` のためサブフォルダ配下でも可）。
スマホでは「ホーム画面に追加」するとアプリのように開けます。

### フォルダ構成

```
src/
  lib/
    catalog.ts         部材カタログ（種類・参考単価・図面での見た目）
    estimate.ts        見積計算
    surveyDef.ts       現調の質問と、注意ポイントの判定
    planFromSurvey.ts  現調 → 平面図の自動レイアウト
    photos.ts          写真の保存（IndexedDB）と縮小
    sample.ts          サンプル案件
  screens/             ホーム・案件・現調・見積・設定の各画面
  plan/                平面図エディタ（描画・操作・吸着の計算）
  view3d/              3D パース（平面図 → three.js のシーン）
  print/               見積書・現調シート（A4 印刷）
  store.ts             状態の保存、画面遷移、確認ダイアログ
tests/                 単体テスト
```

部材や単価を増やすときは `src/lib/catalog.ts`、現調の質問を変えるときは `src/lib/surveyDef.ts` を編集します。

## いまの制限

- 敷地は長方形、道路は 1 面（図の下側）として扱います。
- 3D は平らな地面で表示します（高低差は現調の注意ポイントで知らせるのみ）。
- 平面図の面の部材（コンクリートなど）は長方形で、斜めには置けません（塀・フェンスなどの線は斜めも可）。
- データは端末ごとです。複数人・複数端末での共有には、サーバー側の保存機能の追加が必要です。
